**Toma de decisiones y comunicación estratégica en salud** · *Decision Making and Strategic Communication in Health*

## Resumen

El sílabo en PDF nombraba los artículos de consulta, pero los estudiantes no sabían cuándo ni para qué leerlos.
Con Claude convertimos el sílabo aprobado en un sitio bilingüe para el teléfono: cronograma, evaluación, recursos, contacto y tareas por semana.
Cada versión la revisaron los docentes contra el sílabo. La prueba con estudiantes queda pendiente para el próximo periodo.

## Summary

The PDF syllabus listed the reference articles, but students did not know when or why to read them.
Using Claude, we turned the approved syllabus into a bilingual, phone-friendly site with the schedule, grading, resources, contact details and weekly tasks.
The instructors reviewed every version against the syllabus. Testing with students is planned for the next term.
